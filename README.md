# Hi, I'm Jack

I build tools that help software interact with the real world — from camera-assisted hardware work to evidence-informed design experiments.

I'm interested in the space between **AI agents, practical engineering, and human-centered products**. I work mainly with Python and also build with TypeScript.

## Selected work

- **[camclave](https://github.com/Mondlak1/camclave)** — A consent-gated webcam plugin that lets coding agents inspect physical hardware one still frame at a time. Includes a visible camera-active window and a short demo.
- **[NeuroTarget](https://github.com/Mondlak1/neurotarget)** — A Python CLI and skill for exploring UI and audio stimulus ideas using a brain encoder and curated research. Its recommendations are hypotheses, not guarantees.

I also experiment with mobile apps and small hardware projects. See the [repositories](https://github.com/Mondlak1?tab=repositories) for the work itself.
